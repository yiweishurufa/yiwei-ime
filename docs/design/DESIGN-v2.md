# 一维输入法 Windows 设计语言 v2「澄澈」

> 2026-11-28 起草。用户 03:01：「根据技能重新设计输入法的 UI、交互、模块、动画、图标、字体、排版、颜色、元素等等」——要看得出的整体焕新，不是小修。
> 适用范围：Windows 端 YiweiHelper（设置窗口、首次引导、功能面板、常用语/符号/AI 等浮动面板、托盘菜单、提示气泡、对话框）、
> 小狼毫候选窗配色与样式、托盘 / 语言栏 / 应用图标。安卓端不在本文范围。
>
> token 的唯一出处：`helper/Wpf/DesignV2.cs`（`Tok` 字阶 / 间距 / 圆角 / 动效，`Motion` 动效工具，`PanelPalette` 浮动面板配色）、
> `helper/Brand.cs`（`V2Argb` 候选窗配色、`SystemAccent` 系统强调色）、`scripts/brand_schemes.py`（共享 weasel.yaml 里的同一套配色）、
> `scripts/design/win_icons_v2.py`（图标）。页面代码只引用这些，不写裸数值。对比度自检：`python3 scripts/design/contrast_v2.py`。

## 0. 为什么换、换什么

| | v1「墨线 / 蓝色胶囊」 | v2「澄澈」 |
|---|---|---|
| 一句话 | 纸色底、墨色字，品牌色只点一下 | Windows 11 原生的通透感：云母底、浮起的卡片、跟随系统的强调色 |
| 强调色 | 五个固定品牌色（默认胶囊蓝 #2B5BD7） | **默认跟随 Windows 强调色**（读不到时回退 Windows 默认蓝 #0067C0）；五个品牌色和胶囊仍可选 |
| 设置导航 | 13 个平铺的页面 | 4 组（输入 / 个性化 / 智能与工具 / 数据与关于），组名小标题；选中项左侧强调色竖条（展开动画） |
| 页面头 | 24px 标题 + 一短横 | 28px 标题 + 一行这一页管什么的说明 + 图标瓦片 |
| 设置项 | 图标直接放在卡片里 | 图标放进 36×36 的浅强调色圆角瓦片；卡片悬停有底色过渡；分组标题下有一句说明 |
| 功能面板 | 2 页、31 格（第 1 页 9 格、第 2 页 22 格）、emoji 图标、第 2 页第 10 格以后按不到数字 | 4 个分类页签（常用 / 词库 / 工具 / 文件），每页 ≤ 9 格都能按数字；Fluent 线性图标；淡入上移、悬停、按下、焦点环 |
| 浮动面板 | 圆角 10、阴影 18 | 圆角 12、双层柔和阴影、顶部 1px 高光边（呼应相册 v2 的「玻璃边」） |
| 对话框 | 系统 MessageBox | 一维自己的 Fluent 对话框（标题、正文、主次按钮、Esc/回车），非界面线程时回退系统框 |
| 托盘菜单 | 16 个平铺项，WinForms 默认样式 | 分组 + 「工具」「帮助」两个子菜单，圆角、留白、深浅色跟随系统 |
| 候选窗 | 蓝色胶囊：白底、整颗胶囊高亮 | 「一维 · v2 澄澈」：近白（深色：石墨蓝）底、12px 圆角窗、8px 圆角高亮块、强调色高亮、小一号的灰序号、更柔的阴影 |
| 图标 | 胶囊蓝方块 + 一横一点；中/英托盘是粗体字方块 | 渐变「玻璃方块」+ 一横一点；中 = 实心强调色、英 = 空心描边灰，16px 下也能一眼分清 |

**不变的边界**：不改存储格式和设置键（只改默认值并做一次迁移，见 §8）；不删功能（合并的入口都还能到达，搜索能搜到每一项）；
不打扰、无广告、无遥测、数据只存本机、AI 只在按快捷键时调用；读屏（AutomationProperties）保留并补齐。

## 1. 气质

- **一句话**：安静、通透、跟手。输入法是工具，界面要像 Windows 自己的一部分，打字时完全不抢眼，打开设置时又让人觉得「换新了」。
- **签名细节**：①跟随系统强调色——换了 Windows 强调色，候选窗高亮、设置开关、托盘「中」一起变；②设置页左侧的强调色竖条和图标瓦片；③功能面板打开时的淡入上移。
- **与相册 v2「液态玻璃」的呼应**：共享「浮起的半透明面 + 顶部高光边 + 柔和大阴影」这一材质语言，以及蓝色默认强调色；但 Windows 端不做彩色光晕、不做弹性回弹——遵循 Fluent 的「减速曲线、短时长」。
- **禁止**：渐变文字、emoji 小标题、彩色圆底图标的空状态模板、循环装饰动画、玻璃叠玻璃（浮动面板里的格子是实色卡片，不再半透明）。

## 2. 颜色

### 2.1 设置窗口 / 引导（WPF-UI 主题画刷）

设置窗口和引导继续用 WPF-UI 3.0.5 的 Fluent 主题画刷（`TextFillColorPrimaryBrush`、`CardBackgroundFillColorDefaultBrush` 等），
它们本身就是 Windows 11 设置的色板，深浅色由 `UiTheme.Apply()` 实时切换。v2 新增：

| token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| `Tok.TileBrush` | 强调色 12% | 强调色 22% | 设置项图标瓦片底 |
| `Tok.TileGlyphBrush` | 强调色文字色 | 强调色文字色 | 图标瓦片里的图标 |
| 导航选中条 | 强调色 | 强调色 | 左侧 3×16 竖条 |

背景：Windows 11 用 Mica（云母），Windows 10 降级为 WPF-UI 的纯色底（`ApplicationBackgroundBrush`）。

### 2.2 浮动面板与候选窗中性色（`PanelPalette` / `V2Argb`）

| token | 浅色 | 深色 | 用途 |
|---|---|---|---|
| Back | #F6F8FB（97%） | #1D2129（96%） | 面板底、候选窗底 |
| Card | #FFFFFF | #272C36 | 面板里的格子 |
| CardHover | #EEF2F8 | #313744 | 悬停 |
| Text | #161B26 | #EEF1F6 | 正文、候选字 |
| Dim | #5A6478 | #A4ADBE | 次要文字、提示 |
| Faint | #7A8398 | #7C8598 | 序号、注释（只给 ≥ 3:1 的场合） |
| Line | #E2E7EF | #3A4150 | 发丝线、格子描边 |
| Highlight（顶边高光） | 白 90% | 白 8% | 面板顶部 1px 高光 |

### 2.3 强调色（跟随系统）

- 来源：`HKCU\Software\Microsoft\Windows\DWM\AccentColor`（Windows 10/11 都有）；读不到用 #0067C0。系统强调色变化时（`UserPreferenceChanged`），
  设置窗口立即换色；候选窗配色会在空闲时重写 `weasel.custom.yaml` 并后台重新部署（只在当前用 v2 配色时）。
- 深色档的强调色 = 系统强调色向白提亮 30%。
- **强调色底上的文字**（高亮候选、主按钮）：白 / 近黑 #0B0F17 取对比度高的那个（`Brand.OnAccent`），黄色强调色会自动用黑字。
- **强调色作文字**（页签、选中序号）：浅色档向墨色压 25%、深色档向白提亮 45%，不够 4.5:1 就继续压（`Tok.AccentText`）。
- 用户在「外观 → 强调色」里选了五个品牌色之一时，以用户选择为准，不跟随系统。

### 2.4 对比度（`scripts/design/contrast_v2.py`，WCAG 2.x）

- 正文 / 面板底：浅 16.2、深 14.3；次要文字 / 卡片：浅 5.9、深 6.2；弱文字 / 底：≥ 3.0（只用于序号、注释）。
- 高亮候选字 / 强调色：8 种常见系统强调色（默认蓝、Win 蓝、紫、绿、橙、红、黄、青）× 深浅两档全部 ≥ 4.5。
- 强调色文字 / 面板底：同上 16 组全部 ≥ 4.5。
- 状态不只靠颜色：开关有「开 / 关」文字，功能面板不可用的格子同时降低不透明度并在提示里写原因。

## 3. 字体与字阶

- **只用系统字体，不打包字体**（安装包大小不变）：界面 `Segoe UI Variable Text, Microsoft YaHei UI, Segoe UI`；大标题 `Segoe UI Variable Display, Microsoft YaHei UI`。
  Windows 10 没有 Segoe UI Variable，自动落到 Segoe UI + 微软雅黑 UI。HarmonyOS Sans / MiSans 的许可允许免费使用但对再分发有附加条款，且会让安装包增大 10 MB 以上，不采用。
- 候选窗：候选字微软雅黑 UI（用户可改），序号 Segoe UI，序号比候选字小 3 pt（v2 与胶囊相同）。

| token | 字号 / 行高 (px) | 字重 | 用在 |
|---|---|---|---|
| `Tok.Display` | 28 / 36 | SemiBold | 设置页标题、引导大标题 |
| `Tok.Title` | 20 / 28 | SemiBold | 引导分步标题、对话框标题 |
| `Tok.Subtitle` | 16 / 22 | SemiBold | 品牌名、卡片大标题 |
| `Tok.BodyStrong` | 14 / 20 | SemiBold | 分组标题、功能面板格名 |
| `Tok.Body` | 14 / 20 | Regular | 设置项标题、正文 |
| `Tok.Caption` | 12 / 16 | Regular | 设置项说明、提示、序号 |

字重只用 Regular / SemiBold 两种；层级先靠字号和颜色。

## 4. 间距、圆角、阴影

- 间距 4 的倍数：`Tok.S4 / S8 / S12 / S16 / S24 / S32`。控件内 8–12，同组设置项之间 4，分组之间 24，页边距 32。
- 圆角三级：`Tok.RControl` 4（按钮、输入框、开关跟 WPF-UI）、`Tok.RCard` 8（设置卡片、面板格子）、`Tok.RFlyout` 12（浮动面板、对话框、托盘菜单、候选窗外框）。
  候选窗高亮块 8（胶囊配色仍是整颗胶囊）。
- 阴影（浮动面板、对话框）：两层——近处 0/2/6px 12%，远处 0/8/24px 14%（深色 30% / 35%）；WPF 里用一层 `DropShadowEffect`（Blur 24，Depth 6，Opacity 0.18/0.4）近似。
  有阴影的面不再加粗边框，只留 1px 发丝线。

## 5. 图标

- **界面图标**：统一用 Fluent System Icons（Microsoft，MIT 许可），即 WPF-UI 自带的 `SymbolRegular` 字体——线性、2px 视觉线宽、圆角端点。
  功能面板、设置导航、设置项、托盘菜单都用这一套；功能面板里原来的 emoji 全部换掉。选中态用同一图标的强调色。
- **品牌图标**（`scripts/design/win_icons_v2.py` 生成，多尺寸 ico 16/20/24/32/40/48/64/128/256）：
  - 应用图标 `assets/yiwei.ico`（= `helper/yiwei.ico`）：圆角方块（超椭圆近似，圆角 22%），从 #3B82F6 到 #2551D8 的竖向渐变 + 顶部 45% 高光，
    中间白色「一」横加一个点（沿用 v1 的品牌标）。16/20px 版本加粗横线、去掉高光，避免糊。
  - 语言栏 / 托盘：`assets/zh.ico` 中 = 实心蓝底白字「中」；`assets/en.ico` 英 = 白底、灰蓝描边、灰蓝字「英」。实心 vs 空心，不靠颜色也能分。
  - 助手托盘图标运行时用同一造型绘制，颜色用当前强调色（跟随系统）。
- Kubai 图标集只有图标数据是 MIT，本项目未使用。

## 6. 动效

| 名称 | 时长 | 曲线 | 用在 |
|---|---|---|---|
| `Tok.Fast` | 120 ms | 减速（CubicEase EaseOut） | 悬停底色、按下缩放（0.97） |
| `Tok.Normal` | 200 ms | 减速 | 页面切换（淡入 + 上移 12px）、面板打开（淡入 + 上移 8px）、对话框（淡入 + 0.96→1 缩放） |
| `Tok.Slow` | 300 ms | 减速 | 导航选中条展开（竖向 0→1）、提示条进出 |

- **尊重系统「动画效果」开关**：`Motion.Enabled` 读 `SystemParameters.ClientAreaAnimation`（设置 → 辅助功能 → 视觉效果 → 动画效果）。关掉时所有过渡直接跳到终态；远程桌面会话里也关。
- 只有反馈和转场，没有循环动画；打字路径上（候选窗、中/英提示）不加任何会拖慢出字的动画。
- 动画都作用在 `Opacity` / `RenderTransform` 上，不动布局属性，避免重排。

## 7. 组件与页面

### 7.1 设置窗口
- 左栏（240px）：品牌标 + 「一维输入法」→ 搜索框（Ctrl+F）→ 分组导航。分组：
  - **输入**：常规、输入方案、快捷输入、快捷键、语音
  - **个性化**：外观、常用语、词库
  - **智能与工具**：AI、工具、应用规则
  - **数据与关于**：统计、关于
- 右侧：页面头（图标瓦片 + 28px 标题 + 一句说明）→ 分组标题（14px SemiBold + 可选一句说明）→ 设置卡片。
- 「常规」页按任务重新归组：输入习惯 / 隐私 / 提示 / 显示与输出 / 任务栏图标 / 其他 / 危险操作。原有每一项都保留。
- 搜索：搜标题和说明，结果显示「标题 · 所在页」，回车跳到卡片并闪一下强调色边框；无结果时显示空状态文字。
- 页面切换淡入上移；开关立即生效，需要重新部署的项由底部提示条显示「正在后台重新部署… → ✓ 已生效」。

### 7.2 功能面板（Alt+Q）
- 宽 384；顶部：标题「功能面板」+ 页签（常用 · 词库 · 工具 · 文件；页签不带数字，数字只用来开格子），Tab / Shift+Tab / PgUp / PgDn 换页。
- 每页 ≤ 9 格、3 列，格子 = 36px 图标 + 名称 + 一行提示（快捷键或作用），数字键 1–9 直接打开。
- 悬停：底色过渡；按下：缩放 0.97；键盘选中：2px 强调色焦点环（不只靠底色）。不可用的格子 45% 不透明度，按下时气泡说明原因。
- 打开：淡入 + 上移 8px（200ms）；关闭直接隐藏（不拖慢回到输入）。
- 31 个功能一个不少，按任务重新分到 4 页：常用 9（计算、剪贴板、常用语、符号表情、手写、截图识字、翻译选中、AI 帮写、设置）、
  词库 8（加词、词库体检、自定义短语、纠错规则、屏蔽词、联想记录、同步词库、重新部署）、工具 7（截图翻译、文字工具、局域网互传、
  快捷键总览、双拼键位图、性能体检、检查更新）、文件 7（用户文件夹、词库同步目录、程序目录、方案定制、外观定制、助手日志、导出诊断）。

### 7.3 浮动面板（常用语、符号、AI、手写…）
共用 `PanelParts.Shell`：12px 圆角、v2 阴影、顶部高光边；页签用 `PanelParts.Chip`（选中 = 强调色底 + 强调色上的文字色）。

### 7.4 对话框（`Dialogs`）
一维 Fluent 对话框：圆角 12 的卡片，左侧 ⓘ / ⚠ 图标，标题 + 正文，右下「确定 / 取消」（确认类主按钮在右）。Esc = 取消、回车 = 确定。
只在 WPF 界面线程上用；其他线程（后台任务）自动回退系统 MessageBox，保证不崩。

### 7.5 提示（`ToastHost`）
底部居中的小卡片：成功 ✓ / 进行中 · / 失败 ! 三种前缀图标，深浅色跟随主题，进出 300ms 淡入上移。

### 7.6 托盘菜单
顶层：切换方案 ▸、换主题 ▸ ｜ 功能面板、手写输入、符号与表情、截图识字、加词… ｜ 设置、用户文件夹、工具 ▸（重新部署、同步用户数据、局域网互传）｜ 帮助 ▸（检查更新、导出诊断信息、首次引导）｜ 退出。
所有原有项都在；自绘渲染器：圆角 8 的高亮、28px 行高、深浅色跟随系统。

### 7.7 空状态 / 加载 / 出错
`K.EmptyState(icon, 标题, 一句引导, 可选按钮)`、`K.Loading(文字)`、`K.ErrorState(原因, 重试)`：
图标为线性大图标（48px，次要文字色），不用彩色圆底。用在我的词条（空）、词库体检（检查中 / 没问题 / 出错）、搜索无结果等。

## 8. 候选窗「一维 · v2 澄澈」

- 新增配色 `yiwei_v2` / `yiwei_v2_dark`，设为新安装默认。旧配色（蓝色胶囊、五个墨线品牌色、经典主题、导入主题、我的配色）全部保留可选。
- 颜色见 §2.2；高亮块 = 强调色（跟随系统），文字取白 / 近黑；序号小一号、灰色；注释灰色。
- 样式：外框圆角 12、高亮圆角 8、阴影半径 8 / 下偏 3、高亮横向内边距 8。
- **迁移**（`SettingsVersion` 5）：仍是旧默认「蓝色胶囊 + 胶囊强调色」的用户换成 v2；挑过别的配色的不动。圆角仍是旧默认（8 / 6）的换成 12 / 8。
  想回到胶囊：设置 → 外观 → 候选窗配色 →「蓝色胶囊」。

## 9. 读屏与键盘

- 每个可点的自绘元素（功能面板格子、配色卡片、导航项、对话框按钮）设置 `AutomationProperties.Name`（和 `HelpText` 写提示/快捷键）；
  设置卡片右侧控件自动用卡片标题作读屏名称、说明作帮助文字；提示条、加载与出错状态是读屏「实时区域」。
  （.NET Framework 4.8 没有 `HeadingLevel`，标题层级靠字号区分，读屏按顺序读。）
- Tab 顺序：左栏搜索 → 导航 → 页面内容；焦点可见（WPF-UI 焦点框 + 功能面板自绘焦点环）。

## 10. 验证

- Linux 沙箱：`dotnet build` 编译检查；`python3 scripts/design/contrast_v2.py` 对比度；`python3 scripts/design/win_icons_v2.py --preview` 生成图标预览自查。
- WPF 视觉无法在 Linux 渲染，需在 Windows 真机确认的清单见 `docs/qa-checklist.md`「v2 界面」一节。
