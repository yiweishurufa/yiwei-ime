2. [ ] **智能标点与空格**：中文后自动全角、数字后半角（3.14、10:30）、英文单词中半角（e.g.）；中英之间自动加空格（可选，默认关）。
3. [ ] **自定义词条编辑器**：设置 → 词库 里可视化增删改自己的词和权重，存独立词库（如 yiwei_custom.dict.yaml 经 import_tables 挂载），雾凇每日更新不冲突；可导入/导出 txt。
4. [ ] **从文章学词**：拖入 txt/docx/md 或粘贴文字，本机分词，列出词库没有的词（自动注音，多音字可改），勾选加入第 3 项的自定义词库。完全不联网。

6. [ ] **用户词库体检**：找出疑似打错学进去的词（编码与雾凇读音不符、只用过一次且很久未用等），列表勾选一键清理（走 librime 删词，先自动备份）。
